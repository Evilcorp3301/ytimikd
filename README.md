# ytimikd - Система управления переводами YouTube видео

Система для управления переводами YouTube видео с поддержкой категорий, подкатегорий, каналов, языков и планирования публикаций.

## Технологический стек

### Frontend

- **React 18** + **TypeScript**
- **Vite** - сборщик и dev-сервер
- **Wouter** - маршрутизация
- **TanStack Query** - управление состоянием и кэширование
- **React Hook Form** + **Zod** - формы и валидация
- **Tailwind CSS** - стилизация
- **shadcn/ui** - компоненты UI
- **Radix UI** - примитивы UI
- **date-fns** - работа с датами
- **lucide-react** - иконки

### Backend

- **Express** - веб-сервер
- **Node.js** + **TypeScript**
- **SQLite** (better-sqlite3) - база данных
- **Drizzle ORM** - работа с БД
- **node-cron** - планировщик задач
- **YouTube Data API v3** - интеграция с YouTube

## Основной функционал

### Видео (Videos)

- Добавление видео по YouTube URL
- Автоматическое получение метаданных (название, превью, длительность) через YouTube API
- Редактирование видео
- Удаление видео
- Связь с подкатегориями
- Автоматическое создание переводов для активных языков

### Переводы (Translations)

- Управление переводами для каждого видео
- Статусы: `not_started`, `in_progress`, `completed`
- Связь с каналами публикации
- Планирование публикации (дата и время)
- Автоматический переход из "План" в "История" при наступлении запланированной даты
- Настройка озвучки (имя и пол)
- Автоматическое заполнение данных озвучки из канала

### Категории и подкатегории (Categories & Subcategories)

- Иерархическая структура: Категории → Подкатегории
- Видео связаны с подкатегориями (один-к-одному)
- Каналы связаны с подкатегориями (многие-ко-многим)
- Управление категориями и подкатегориями
- Статистика по категориям (количество видео и каналов)

### Каналы (Channels)

- Управление каналами публикации
- Связь с подкатегориями (многие-ко-многим)
- Связь с языками (defaultLanguage)
- Настройки озвучки по умолчанию
- Фильтрация каналов по подкатегории и языку

### Языки (Languages)

- Управление языками для переводов
- Активация/деактивация языков
- Сортировка языков
- Автоматическое создание переводов для активных языков при добавлении видео

### Планирование (Scheduled)

- Страница "План" - запланированные публикации
- Фильтрация по каналам
- Сортировка по дате и времени
- Группировка по каналам
- Отображение времени до публикации
- Автоматический переход в "История" при наступлении даты

### История (History)

- Страница "История" - опубликованные переводы
- Фильтрация по языкам
- Поиск по названию видео
- Группировка по видео

### Очередь (Queue)

- Главная страница с видео в работе
- Фильтрация по категориям/подкатегориям
- Фильтрация по статусу переводов
- Поиск по названию
- Управление переводами через диалог

### Активность (Activity)

- Журнал всех действий в системе
- Фильтрация по типам событий
- Фильтрация по датам
- Удаление записей активности

### Настройки (Settings)

- Хранение настроек в базе данных
- YouTube API ключ (хранится в настройках)

### Поиск (Search)

- Глобальный поиск по видео и каналам
- Поиск по URL, ID, названию

## API Endpoints

### Videos

- `GET /api/videos` - Получить все видео
- `GET /api/videos/:id` - Получить видео по ID
- `POST /api/videos` - Создать видео
- `PATCH /api/videos/:id` - Обновить видео
- `DELETE /api/videos/:id` - Удалить видео

### Channels

- `GET /api/channels` - Получить каналы (с фильтрами subcategoryId, language)
- `GET /api/channels/:id` - Получить канал по ID
- `GET /api/channels/:id/subcategories` - Получить подкатегории канала
- `GET /api/channels/stats` - Статистика по каналам
- `POST /api/channels` - Создать канал
- `PATCH /api/channels/:id` - Обновить канал
- `DELETE /api/channels/:id` - Удалить канал

### Translations

- `GET /api/translations` - Получить переводы (с фильтрами archived, scheduled, channelId)
- `GET /api/translations/:id` - Получить перевод по ID
- `POST /api/translations` - Создать перевод
- `PATCH /api/translations/:id` - Обновить перевод
- `DELETE /api/translations/:id` - Удалить перевод

### Languages

- `GET /api/languages` - Получить языки
- `POST /api/languages` - Создать язык
- `PATCH /api/languages/:id` - Обновить язык
- `DELETE /api/languages/:id` - Удалить язык

### Categories

- `GET /api/categories` - Получить категории
- `GET /api/categories/stats` - Статистика по категориям
- `GET /api/categories/:id` - Получить категорию по ID
- `POST /api/categories` - Создать категорию
- `PATCH /api/categories/:id` - Обновить категорию
- `DELETE /api/categories/:id` - Удалить категорию

### Subcategories

- `GET /api/subcategories` - Получить подкатегории (с фильтром categoryId)
- `GET /api/subcategories/:id` - Получить подкатегорию по ID
- `POST /api/subcategories` - Создать подкатегорию
- `PATCH /api/subcategories/:id` - Обновить подкатегорию
- `DELETE /api/subcategories/:id` - Удалить подкатегорию

### Activity Logs

- `GET /api/activity-logs` - Получить записи активности (с фильтрами startDate, endDate, limit)
- `DELETE /api/activity-logs` - Удалить записи активности (с фильтрами startDate, endDate)

### Settings

- `GET /api/settings` - Получить все настройки
- `PUT /api/settings` - Обновить настройки

### YouTube

- `GET /api/youtube/video-info` - Получить метаданные видео (videoId)
- `GET /api/youtube/thumbnail` - Скачать превью видео (videoId)

### Search

- `GET /api/search` - Поиск по видео и каналам (q)

## Установка и запуск

### Требования

- Node.js 20+

```bash
npm install
```

База данных SQLite используется по умолчанию. Файл базы данных будет создан автоматически при первом запуске.

Создайте файл `.env` в корне проекта (опционально):

```env

PORT=5000

YOU_TUBE_API=your_api_key_here
```

## База данных

### SQLite

Проект использует SQLite как базу данных по умолчанию. Файл базы данных `database.sqlite` создается автоматически в корне проекта.

### Схема базы данных

Схема определена в `shared/schema.ts` и управляется через Drizzle ORM.

Основные таблицы:

- `videos` - видео
- `translations` - переводы
- `channels` - каналы
- `categories` - категории
- `subcategories` - подкатегории
- `channel_subcategories` - связь каналов с подкатегориями (многие-ко-многим)
- `default_languages` - языки
- `activity_logs` - записи активности
- `settings` - настройки

### Миграции

Применение изменений схемы:

```bash
npm run db:push
```

## YouTube API интеграция

### Получение метаданных видео

При добавлении видео автоматически получаются метаданные (название, превью, длительность) через YouTube Data API v3.

### Настройка API ключа

API ключ можно указать двумя способами:

1. Через переменную окружения `YOU_TUBE_API`
2. Через настройки в UI (сохраняется в базе данных)

Приоритет: переменная окружения → настройки из БД

### Получение превью

Превью загружается с YouTube по приоритету качества:

- maxresdefault
- sddefault
- hqdefault
- mqdefault

## Автоматические задачи

### Cron задача

Каждую минуту выполняется автоматическая проверка запланированных переводов:

- Переводы с наступившей датой публикации автоматически перемещаются из "План" в "История"
- Устанавливается `publishedDate` и удаляется `scheduledDate`
- Статус устанавливается в `completed`
