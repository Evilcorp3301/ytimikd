## [Unreleased]

### Добавлено

- Инструменты для поддержания качества кода (ESLint, Prettier, Husky, Commitlint)
- Автоматические проверки перед коммитом
- Dependabot для автоматического обновления зависимостей

## [1.0.0] - Текущая версия

### Добавлено

- Управление видео YouTube
- Управление переводами с планированием публикации
- Управление каналами публикации
- Управление языками
- Управление категориями и подкатегориями
- Интеграция с YouTube Data API v3
- Автоматический переход переводов из "План" в "История"
- Система активности (журнал действий)
- Поиск по видео и каналам
- SQLite база данных
- Netlify деплой
