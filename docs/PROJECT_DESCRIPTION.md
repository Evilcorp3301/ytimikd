# Описание проекта YTimikD

> **Дата создания**: 2025-12-17  
> **Версия**: 1.0  
> **Цель документа**: Полное описание логики работы проекта, архитектуры и пользовательских сценариев

---

## 🎯 Общее описание проекта

**YTimikD** — это внутренний инструмент для управления переводами YouTube видео. Проект предназначен для двух ролей:

- **Куратор** — добавляет исходные видео в очередь и настраивает список языков для перевода
- **Публикатор** — переводит видео по языкам, публикует на YouTube и фиксирует результаты

Проект представляет собой полнофункциональное веб-приложение с современным стеком технологий, автоматизацией процессов и удобным интерфейсом для отслеживания прогресса переводов.

## 🏗️ Архитектура проекта

### Технологический стек

**Frontend:**
- **Vite** — сборщик и dev-сервер
- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Tailwind CSS** — стилизация
- **shadcn/ui** — компонентная библиотека
- **Wouter** — роутинг
- **TanStack Query** — управление состоянием и кэширование
- **React Hook Form + Zod** — формы и валидация

**Backend:**
- **Express.js** — веб-сервер
- **Node.js** — runtime
- **TypeScript** — типизация
- **Drizzle ORM** — работа с базой данных
- **node-cron** — планировщик задач

**База данных:**
- **PostgreSQL** (Supabase) — основное хранилище
- **MemoryStorage** — fallback для разработки без БД

**Дополнительно:**
- **YouTube Data API v3** — получение метаданных видео
- **Telegram Bot API** — уведомления о срочных публикациях

### Структура базы данных

#### Основные таблицы:

1. **`videos`** — исходные видео
   - `id` (UUID) — уникальный идентификатор
   - `url` (text) — ссылка на YouTube видео
   - `title` (text) — название (автозаполняется из YouTube API)
   - `thumbnailUrl` (text) — превью (автозаполняется)
   - `subcategoryId` (UUID) — связь с подкатегорией
   - `createdAt` (timestamp) — дата добавления
   - `isArchived` (boolean) — флаг архивации (deprecated, не используется)

2. **`translations`** — переводы видео
   - `id` (UUID) — уникальный идентификатор
   - `videoId` (UUID) — связь с видео
   - `language` (text) — код языка (например, "EN", "DE", "ES")
   - `status` (text) — статус: `not_started`, `in_progress`, `completed`
   - `translatedUrl` (text) — ссылка на опубликованное видео
   - `channelId` (UUID) — канал для публикации
   - `voiceOverName` (text) — имя голоса
   - `voiceOverGender` (text) — пол голоса: `male`, `female`
   - `scheduledDate` (timestamp) — запланированная дата публикации
   - `publishedDate` (timestamp) — фактическая дата публикации
   - `createdAt` (timestamp) — дата создания

3. **`channels`** — YouTube каналы
   - `id` (UUID) — уникальный идентификатор
   - `name` (text) — название канала
   - `url` (text) — ссылка на канал
   - `defaultLanguage` (text) — язык по умолчанию
   - `voiceOverName` (text) — имя голоса
   - `voiceOverGender` (text) — пол голоса

4. **`categories`** и **`subcategories`** — система категоризации
   - Иерархическая структура: Категория → Подкатегория
   - Видео связаны с подкатегорией
   - Каналы связаны с подкатегориями (many-to-many)

5. **`default_languages`** — языки по умолчанию
   - При добавлении видео автоматически создаются переводы для активных языков

6. **`activity_logs`** — лог всех действий
   - Записываются все важные события (добавление видео, завершение переводов и т.д.)

7. **`settings`** — настройки приложения
   - YouTube API ключ
   - Telegram Bot Token и Chat ID
   - Флаги уведомлений

## 🔄 Логика работы системы

### 1. Жизненный цикл видео

#### Этап 1: Добавление видео (Куратор)

**Действия пользователя:**
1. Переходит на страницу "Очередь" (`/queue`)
2. Нажимает кнопку "Добавить"
3. Вводит URL YouTube видео
4. Опционально выбирает подкатегорию (для организации контента)
5. Сохраняет форму

**Что происходит на бэкенде:**
1. Валидация URL и извлечение YouTube Video ID
2. **Автоматическое получение метаданных** (если настроен YouTube API ключ):
   - Название видео
   - Превью (thumbnail)
   - Название канала
3. Создание записи в таблице `videos`
4. **Автоматическое создание переводов** для всех активных языков из `default_languages`:
   - Для каждого активного языка создается запись в `translations` со статусом `not_started`
5. Запись в `activity_logs`: событие `video_added`
6. Возврат видео со всеми переводами на фронтенд

**Результат:**
- Видео появляется в очереди
- Автоматически созданы переводы для всех активных языков
- Все переводы имеют статус `not_started`

#### Этап 2: Работа с переводами (Публикатор)

**Действия пользователя:**
1. На странице "Очередь" видит карточки видео с:
   - Превью на всю ширину (16:9)
   - Прогресс-баром (X/Y готово переводов)
   - Группированными badges по статусу (готово/в работе/не начато)
   - Индивидуальными чипами языков
   - Badge категории/подкатегории
2. Кликает на чип языка (например, "EN")
3. Открывается диалог перевода

**Умная фильтрация каналов:**
- Если у видео есть подкатегория, показываются только каналы, связанные с этой подкатегорией
- Дополнительно фильтруются по языку перевода
- Это помогает избежать ошибок при выборе канала

**В диалоге перевода пользователь может:**

**Вариант A: Немедленная публикация**
1. Выбирает канал для публикации
2. Вводит ссылку на уже опубликованное видео (`translatedUrl`)
3. Опционально указывает имя и пол голоса
4. Выбирает статус: `not_started` или `completed`
5. Сохраняет

**Вариант B: Планирование публикации**
1. Выбирает канал
2. Включает режим "Запланировать публикацию"
3. Выбирает дату и время (в часовом поясе МСК)
4. Вводит ссылку на видео (если уже готово)
5. Сохраняет

**Что происходит на бэкенде:**

При сохранении перевода:
1. Если указан `translatedUrl` и статус `completed`:
   - Автоматически устанавливается `publishedDate` (если не было)
   - Запись в `activity_logs`: событие `translation_completed`
2. Если указан `scheduledDate` в будущем:
   - Перевод остается со статусом `in_progress` или `completed`
   - `publishedDate` остается `null` до наступления запланированной даты
   - Запись в `activity_logs`: событие `schedule_created` или `schedule_updated`

**Результат:**
- Перевод обновлен в базе данных
- Если статус `completed` и есть `translatedUrl` — появляется в "Истории"
- Если есть `scheduledDate` — появляется в "Плане"

#### Этап 3: Автоматический переход scheduled → completed

**Автоматический процесс (cron job, каждую минуту):**

Функция `checkScheduledTranslationsAndNotify()` в `server/telegram.ts`:

1. Получает все переводы с `scheduledDate` не null
2. Для каждого перевода:
   - Вычисляет время до публикации
   - **Если время наступило (или прошло) И есть `translatedUrl`:**
     - Устанавливает `status = "completed"`
     - Устанавливает `publishedDate` (если не было)
     - Очищает `scheduledDate` (перевод больше не в "Плане")
     - Перевод автоматически появляется в "Истории"
   - **Если до публикации осталось менее 2 часов:**
     - Отправляет Telegram уведомление (если настроено)
     - Уведомление отправляется только один раз для каждого перевода

**Логика:**
- Нет концепции "просрочено" — запланированные переводы автоматически переходят в "Историю" при наступлении времени
- Если `translatedUrl` не указан, перевод остается в "Плане" до ручного обновления

#### Этап 4: Просмотр истории

**Действия пользователя:**
1. Переходит на страницу "История" (`/history`)
2. Видит список всех завершенных переводов
3. Может видеть:
   - Название исходного видео
   - Язык перевода
   - Канал публикации
   - Дату публикации
   - Ссылку на опубликованное видео

**Что происходит на бэкенде:**
- Запрос всех переводов с `status = "completed"` и `publishedDate` не null
- Сортировка по дате публикации (новые сверху)

### 2. Система категорий и подкатегорий

**Назначение:**
- Организация контента по тематикам
- Умная фильтрация каналов при добавлении переводов
- Статистика использования

**Структура:**
- **Категория** (например, "Истории")
  - **Подкатегория 1** (например, "Всемирная история")
  - **Подкатегория 2** (например, "История древнего мира")

**Связи:**
- Видео → Подкатегория (one-to-many)
- Каналы → Подкатегории (many-to-many через `channel_subcategories`)

**Использование:**
1. При добавлении видео можно выбрать подкатегорию
2. При добавлении канала можно выбрать несколько подкатегорий
3. При открытии диалога перевода каналы автоматически фильтруются:
   - По подкатегории видео
   - По языку перевода

**Результат:**
- Пользователь видит только релевантные каналы
- Меньше ошибок при выборе канала
- Лучшая организация контента

### 3. Управление каналами

**Действия пользователя:**
1. Переходит на страницу "Каналы" (`/channels`)
2. Нажимает "Добавить"
3. Вводит:
   - URL канала (автоматически извлекается название через YouTube API)
   - Язык по умолчанию
   - Имя и пол голоса
   - Подкатегории (multi-select, группированные по категориям)
4. Сохраняет

**Что происходит на бэкенде:**
1. Валидация URL канала
2. Автоматическое получение названия через YouTube API
3. Создание записи в `channels`
4. Создание связей в `channel_subcategories`
5. Запись в `activity_logs`: событие `channel_added`

---

### 4. Управление языками по умолчанию

**Действия пользователя:**
1. Переходит на страницу "Языки" (`/languages`)
2. Видит список всех языков
3. Может:
   - Добавить новый язык
   - Активировать/деактивировать язык (toggle `isActive`)
   - Изменить порядок сортировки

**Логика:**
- Только активные языки (`isActive = true`) автоматически создаются при добавлении нового видео
- Деактивация языка не удаляет существующие переводы, но предотвращает создание новых

---

### 5. Страница "План" (Scheduled)

**Назначение:**
- Отслеживание запланированных публикаций
- Визуализация срочности (через 2 часа, через 1 час и т.д.)
- Управление расписанием

**Что видит пользователь:**
1. Список всех переводов с `scheduledDate` в будущем
2. Для каждого перевода:
   - Название видео
   - Язык
   - Канал
   - Категория/подкатегория (badge)
   - Запланированная дата и время
   - Время до публикации (обновляется каждую минуту)
   - Badge срочности:
     - "Срочно" (красный) — менее 1 часа
     - "Скоро" (оранжевый) — менее 2 часов
     - Обычный — более 2 часов

**Важно:**
- Нет концепции "просрочено" — все запланированные переводы автоматически переходят в "Историю" при наступлении времени
- Если `translatedUrl` не указан, перевод остается в "Плане" до ручного обновления

---

### 6. Telegram уведомления

**Настройка:**
1. Переходит на страницу "Настройки" (`/settings`)
2. Вводит:
   - Telegram Bot Token
   - Chat ID
   - Включает уведомления (`notifyScheduleWarning`)

**Логика работы:**
- Cron job запускается каждую минуту
- Проверяет все запланированные переводы
- Если до публикации осталось менее 2 часов:
  - Отправляет уведомление в Telegram
  - Уведомление отправляется только один раз для каждого перевода
  - Содержит: название видео, язык, канал, оставшееся время

**Формат уведомления:**
```
⚠️ Urgent: Publication deadline approaching!

📹 Video: [Название видео]
🌐 Language: [Язык]
📺 Channel: [Канал]
⏰ Time remaining: [X минут/часов]

Please complete the translation and publish soon!
```

**Действия пользователя:**

- Endpoint `GET /api/search?q=<query>`
- Поиск по:
  - Видео: название, URL, ID
  - Каналы: название, URL, ID
- Case-insensitive поиск (ILIKE в PostgreSQL)

## 👤 Детальные пользовательские сценарии

### Сценарий 1: Добавление нового видео и работа с переводами

**Шаг 1: Куратор добавляет видео**
1. Открывает страницу "Очередь"
2. Нажимает "Добавить"
3. Вставляет URL: `https://www.youtube.com/watch?v=ABC123`
4. Выбирает подкатегорию: "Истории / Всемирная история"
5. Нажимает "Сохранить"
6. Система автоматически:
   - Получает название и превью из YouTube
   - Создает переводы для всех активных языков (EN, DE, ES, FR и т.д.)

**Шаг 2: Публикатор начинает работу**
1. Видит новое видео в очереди
2. Видит прогресс: "0/5 готово" (если 5 активных языков)
3. Кликает на чип "EN" (английский)
4. Открывается диалог перевода
5. Видит только каналы, связанные с подкатегорией "Всемирная история" и поддерживающие английский язык

**Шаг 3: Публикатор публикует перевод**
1. Выбирает канал: "History Channel EN"
2. Вводит ссылку на опубликованное видео: `https://www.youtube.com/watch?v=XYZ789`
3. Выбирает статус: "Завершено"
4. Нажимает "Сохранить"
5. Система автоматически:
   - Устанавливает `status = "completed"`
   - Устанавливает `publishedDate = now()`
   - Записывает событие в лог активности
6. Прогресс обновляется: "1/5 готово"
7. Перевод появляется в "Истории"

**Шаг 4: Публикатор планирует следующий перевод**
1. Кликает на чип "DE" (немецкий)
2. Выбирает канал: "History Channel DE"
3. Включает "Запланировать публикацию"
4. Выбирает дату: завтра, 18:00
5. Вводит ссылку на готовое видео (уже загружено на YouTube)
6. Нажимает "Сохранить"
7. Перевод появляется в "Плане" с badge "Скоро" (если менее 2 часов) или обычным
8. За 2 часа до публикации приходит Telegram уведомление
9. В 18:00 система автоматически:
   - Переводит статус в `completed`
   - Устанавливает `publishedDate`
   - Очищает `scheduledDate`
   - Перевод появляется в "Истории"

1. В назначенное время система автоматически:
   - Переводит статус в `completed`

## 🔧 Технические детали

### Автоматизация

1. **Автоматическое получение метаданных YouTube:**
   - При добавлении видео без названия/превью
   - Используется YouTube Data API v3
   - Fallback на дефолтное превью, если API недоступен

2. **Автоматическое создание переводов:**
   - При добавлении видео создаются переводы для всех активных языков
   - Статус по умолчанию: `not_started`

3. **Автоматический переход scheduled → completed:**
   - Cron job каждую минуту
   - Проверяет все переводы с `scheduledDate`
   - Автоматически переводит в `completed` при наступлении времени

4. **Автоматические уведомления:**
   - Telegram уведомления за 2 часа до публикации
   - Отправляются только один раз для каждого перевода

### Часовой пояс

- Все даты хранятся в UTC в базе данных
- UI показывает даты в часовом поясе **МСК (Europe/Moscow)**
- При выборе даты/времени пользователь работает в МСК
- Конвертация происходит автоматически

### Умная фильтрация

- **Каналы при добавлении перевода:**
  - Фильтруются по подкатегории видео
  - Фильтруются по языку перевода
  - Показываются только релевантные каналы

- **Видео в очереди:**
  - Можно фильтровать по категории
  - Можно фильтровать по подкатегории

### Логирование активности

Все важные действия записываются в `activity_logs`:
- `video_added` — добавление видео
- `translation_started` — начало перевода
- `translation_completed` — завершение перевода
- `video_deleted` — удаление видео
- `schedule_created` — создание расписания
- `schedule_updated` — обновление расписания
- `channel_added` — добавление канала
- И другие события

## 📊 Визуализация данных

### Карточки видео

**Элементы:**
1. **Превью** — на всю ширину, 16:9, с hover-эффектом (медленный zoom)
2. **Overlay при hover** — затемнение и кнопки действий (YouTube, Download)
3. **Название видео** — или "Без названия", если не указано
4. **Badge категории/подкатегории** — если выбрана
5. **Прогресс-бар** — внизу карточки, показывает X/Y готово
6. **Группированные badges статусов:**
   - "✓ X готово" (зеленый)
   - "◐ X в работе" (синий)
   - "X не начато" (серый)
7. **Индивидуальные чипы языков** — кликабельные, открывают диалог перевода

### Страница "План"

**Элементы:**
1. **Список запланированных переводов**
2. **Badge срочности:**
   - Красный "Срочно" — менее 1 часа
   - Оранжевый "Скоро" — менее 2 часов
3. **Время до публикации** — обновляется каждую минуту
4. **Категория/подкатегория** — badge на карточке

## 📝 Заключение

YTimikD — это полнофункциональный инструмент для управления переводами YouTube видео с автоматизацией процессов, умной фильтрацией и удобным интерфейсом. Система поддерживает два основных workflow:

1. **Немедленная публикация** — перевод готов, сразу публикуется и фиксируется
2. **Планирование публикации** — перевод готов заранее, публикация запланирована на будущее

Все процессы автоматизированы там, где это возможно, что позволяет пользователям сосредоточиться на основной работе — создании качественных переводов.
