# План улучшения дизайна страницы категорий

> **Дата**: 2025-12-17  
> **Статус**: ✅ Реализовано (финальный минималистичный дизайн без градиентов)

## ✅ Итоговое решение (финальный дизайн)

После итераций (включая “градиентные акценты”, которые визуально **не подошли** стилю проекта) принята финальная версия:

- **Карточки категорий**
  - Чистый `Card` без ярких градиентных полос
  - Тонкий акцент: `border-l-4 border-l-primary`
  - Иконка в `bg-primary/10`
  - Статистика под описанием в отдельном блоке с `border-t` и иконками `Video` / `Tv`
- **Подкатегории**
  - Простые строки с border и лёгким hover (без визуального шума)
  - Быстрые действия появляются на hover
- **Консистентность**
  - Совпадает по ощущению с `Queue`/`Channels` (минимализм, читабельность, аккуратные отступы)

---

## 🎨 Проблемы текущего дизайна

1. **Плоская визуальная иерархия** - все карточки выглядят одинаково
2. **Нет визуальных акцентов** - отсутствуют градиенты, цвета, выразительные элементы
3. **Статистика слабо видна** - мелкий текст, нет акцентов
4. **Подкатегории выглядят скучно** - простые border карточки
5. **Нет визуального разделения** - все элементы на одном уровне

## ✨ Предложения по улучшению

### 1. Карточки категорий (без градиентной перегрузки)
- Тонкий акцент (левая полоса), без ярких градиентных плашек
- Мягкие тени и лёгкий hover, без “кричащих” цветов
- Иконка категории (аккуратно, в `bg-primary/10`)

### 2. Визуализация статистики
- Иконки + числа в `text-xs text-muted-foreground` (без цветных бейджей)
- Блок статистики отделён `border-t`

### 3. Подкатегории как tags/badges
- Компактные строки/ячейки с border (как список внутри карточки)
- Лёгкий hover `hover:bg-muted/50`
- Управляющие иконки показывать на hover

### 4. Улучшенная типографика
- Более крупные заголовки категорий
- Лучший spacing между элементами
- Четкая визуальная иерархия

### 5. Цветовые схемы
- Каждая категория может иметь свой цвет (генерируется или выбирается)
- Градиенты на основе цветовой схемы
- Консистентность с брендом
