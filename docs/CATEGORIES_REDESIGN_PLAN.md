# План улучшения дизайна страницы категорий

> **Дата**: 2025-12-16  
> **Статус**: В разработке

## 🎨 Проблемы текущего дизайна

1. **Плоская визуальная иерархия** - все карточки выглядят одинаково
2. **Нет визуальных акцентов** - отсутствуют градиенты, цвета, выразительные элементы
3. **Статистика слабо видна** - мелкий текст, нет акцентов
4. **Подкатегории выглядят скучно** - простые border карточки
5. **Нет визуального разделения** - все элементы на одном уровне

## ✨ Предложения по улучшению

### 1. Карточки категорий с градиентными акцентами
- Градиентный border-top или акцентная полоса
- Улучшенные тени с depth
- Hover эффекты с легким подъемом
- Иконка категории (опционально)

### 2. Визуализация статистики
- Крупные числа с цветовыми акцентами
- Иконки с цветами (Video - синий, Tv - фиолетовый)
- Badge-подобное отображение вместо простого текста
- Прогресс-индикаторы (если есть лимиты)

### 3. Подкатегории как tags/badges
- Цветовые акценты для подкатегорий
- Лучшие hover эффекты
- Компактное отображение с визуальным разделением
- Индикаторы активности

### 4. Улучшенная типографика
- Более крупные заголовки категорий
- Лучший spacing между элементами
- Четкая визуальная иерархия

### 5. Цветовые схемы
- Каждая категория может иметь свой цвет (генерируется или выбирается)
- Градиенты на основе цветовой схемы
- Консистентность с брендом
