# Анализ и улучшение функций "Архив" и "Запланированные"

## Дата создания
2025-12-17

## Цель анализа
Провести глубокий анализ логики и внешнего вида функций "Архив" и "Запланированные", найти решения проблем и предложить улучшения на основе современных UI/UX практик.

---

## 1. Текущее состояние

### 1.1 Архив
**Назначение:** Хранение видео, которые были вручную архивированы пользователем (отменены).

**Текущая реализация:**
- Отображает список архивированных видео в простом списке
- Показывает миниатюру, название и дату архивирования
- Фильтрует только видео с `isArchived === true` и `archivedReason === "manual"`

**Проблемы:**
- Простой горизонтальный список не использует пространство эффективно
- Не соответствует дизайну карточек на других страницах (Queue, Categories)
- Отсутствует визуальная иерархия и интерактивность

### 1.2 Запланированные
**Назначение:** Отслеживание запланированных публикаций переводов.

**Текущая реализация:**
- Отображает список запланированных переводов
- Показывает визуальные индикаторы срочности (normal/warning/urgent)
- Реальное время обновления через каждую минуту
- Фильтрация по каналам

**Проблемы / решения:**
- ✅ Убрана логика “просрочено” — “Запланированные” используются только для отслеживания плановой публикации

## 2. Проведенный анализ в интернете

### 2.1 Лучшие практики для архивов
На основе исследования современных CMS и платформ управления контентом:

1. **Grid Layout (Сетка):**
   - Эффективное использование пространства экрана
   - Визуальная консистентность с другими разделами
   - Легкое сканирование большого количества элементов

2. **Card-based Design (Карточный дизайн):**
   - Миниатюра сверху (aspect-video)
   - Основная информация внизу
   - Hover эффекты для интерактивности

3. **Минималистичный подход:**
   - Только необходимая информация
   - Четкая типографика
   - Достаточные отступы

### 2.2 Лучшие практики для запланированных публикаций

1. **Простота статусов:**
   - Избегание сложных статусов типа "просрочено"
   - Фокус на отслеживании времени до публикации
   - Визуальные индикаторы срочности (норма/скоро/срочно)

2. **Real-time Updates:**
   - Обновление времени до публикации в реальном времени
   - Минимальные визуальные изменения (без мигания)

3. **Категоризация:**
   - Фильтрация по каналам
   - Возможность сортировки по дате
   - Группировка по датам (опционально)

## 3. Внесенные улучшения

### 3.1 Архив

**Изменения (реализовано):**
1. ✅ Переход с списка на grid layout (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`)
2. ✅ Полноразмерные миниатюры видео (aspect-video) сверху карточки
3. ✅ Информация (название, дата) внизу карточки
4. ✅ Hover эффекты (карточный hover + тени)
5. ✅ Консистентность с дизайном карточек на Queue и Categories страницах

**Результат:**
- Более эффективное использование пространства
- Лучшая визуальная иерархия
- Современный и консистентный дизайн

### 3.2 Запланированные

**Изменения (реализовано):**
1. ✅ Удалена логика "просрочено" из функции `getTimeUntilString`
2. ✅ Убрана проверка `if (minutesUntil < 0) return "просрочено"`
3. ✅ Теперь функция просто показывает время до публикации или форматированную дату

**Результат:**
- Соответствие требованию: "нет понятия просрочено"
- Простое отслеживание запланированных публикаций
- Фокус на времени до публикации, а не на статусах
