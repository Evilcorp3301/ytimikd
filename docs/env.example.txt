Local dev environment variables
===============================

Required (to use Postgres/Supabase storage):

  DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/postgres

Notes:
- If your DB password contains special characters (e.g. @, !, #, /, :),
  you must URL-encode them inside the connection string.
  Common encodings:
    @ -> %40
    ! -> %21
    # -> %23
    / -> %2F
    : -> %3A

Optional:

  PORT=5000
