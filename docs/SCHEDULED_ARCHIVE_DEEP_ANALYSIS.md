## 📊 Текущая логика работы

### 1. Страница "План" (Scheduled)

**Что показывает:**
- Все переводы с `scheduledDate !== null`
- Сортировка по `scheduledDate` (от ближайших к дальним)
- Фильтр по каналам
- Индикаторы срочности (urgent/warning/normal)

**Логика автоматического перехода:**
```typescript
// Cron job каждую минуту (server/telegram.ts)
if (scheduledDate <= now && translatedUrl существует) {
  // Автоматически:
  - status = "completed"
  - publishedDate = now (если не было)
  - scheduledDate = null (убирает из "План")
  // Если все переводы видео completed → видео auto-архивируется
}
```

**Проблемы:**
1. ❌ Показывает переводы, которые уже `completed`, но имеют `scheduledDate` в будущем
2. ❌ Не показывает, что перевод уже готов (если `status === "completed"` но `scheduledDate` еще не наступил)
3. ❌ Нет группировки по видео (один перевод = одна карточка)
4. ❌ Нет фильтрации по статусу (готов/не готов)
5. ❌ Нет возможности массовых действий

---

### 2. Страница "Архив" (Archive)

**Что показывает:**
- Только видео с `isArchived === true` И `archivedReason === "manual"`
- Grid layout с карточками
- Дата архивирования

**Проблемы:**
1. ❌ **КРИТИЧНО**: Не показывает auto-архивированные видео (`archivedReason === "auto"`)
2. ❌ Нет информации о переводах в архивированном видео
3. ❌ Нет возможности восстановить из архива
4. ❌ Нет фильтрации (по дате, причине архивирования)
5. ❌ Нет поиска

---

### 3. Страница "История" (History)

**Что показывает:**
- Видео с хотя бы одним переводом, у которого есть `translatedUrl`
- Группировка по видео
- Прогресс переводов
- Раскрывающийся список переводов

**Проблемы:**
1. ❌ Пересекается с логикой "Архив" (auto-архивированные видео могут быть и там, и там)
2. ❌ Показывает видео, которые еще в работе (если хотя бы один перевод опубликован)
3. ❌ Нет четкого разделения: что в "Истории", а что в "Архиве"

## 🔍 Анализ состояний данных

### Состояния видео:

```
1. ACTIVE (в очереди)
   - isArchived = false
   - Есть переводы со статусом not_started/in_progress
   - Может иметь completed переводы, но не все

2. AUTO-ARCHIVED (автоматически завершено)
   - isArchived = true
   - archivedReason = "auto"
   - Все переводы completed
   - Нет scheduled переводов

3. MANUAL-ARCHIVED (отменено вручную)
   - isArchived = true
   - archivedReason = "manual"
   - Может иметь незавершенные переводы
```

### Состояния переводов:

```
1. NOT_STARTED
   - status = "not_started"
   - scheduledDate может быть или нет

2. IN_PROGRESS
   - status = "in_progress"
   - scheduledDate может быть или нет

3. COMPLETED (готов, но не опубликован)
   - status = "completed"
   - translatedUrl = null
   - scheduledDate может быть в будущем

4. PUBLISHED (опубликован)
   - status = "completed"
   - translatedUrl !== null
   - publishedDate установлен

5. SCHEDULED (запланирован)
   - scheduledDate !== null
   - Может быть в любом статусе (not_started/in_progress/completed)
```
