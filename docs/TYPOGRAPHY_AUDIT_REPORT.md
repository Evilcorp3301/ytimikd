## Оставлено без изменений (правильное использование)

### Прямые размеры для мелких элементов (это нормально)

1. **Badges** - используют `text-xs` напрямую (правильно, так как это мелкие элементы)
2. **Метаданные** - используют `text-xs text-muted-foreground/60` (правильно)
3. **Кнопки size="sm"** - используют `text-xs` (правильно, это вариант размера)
4. **Мелкие подсказки** - используют `text-xs` (правильно)

### Переопределения font-weight (намеренные)

1. **categories.tsx** и **channels.tsx** - `text-heading-3 font-medium`
   - Это намеренное переопределение `font-semibold` на `font-medium` для названий категорий/каналов
   - Оставлено без изменений, так как это специфический стиль для этих элементов

2. **languages.tsx** - `font-medium` для названия языка
   - Это не заголовок, а основной текст с акцентом
   - Оставлено без изменений
